# Marketing workspace

- `TEAM.md` — the AI team's brief and rules (read first).
- `reports/` — weekly audit and manager reports (newest first by date in the file name).
- `drafts/social`, `drafts/outreach`, `drafts/content` — drafts waiting for a person to approve, edit and publish/send.

To approve a draft: edit it if needed, publish/send it yourself, then add `Status: done (<date>, <who>)` at its top so
the team knows.
